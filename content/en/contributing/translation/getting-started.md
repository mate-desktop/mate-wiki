### Initial Setup

We use a [weblate instance](https://translate.fedoraproject.org/) for translating the MATE Desktop into several languages.

How to help translating:

1. Register for a free account at <https://accounts.fedoraproject.org/>.

2. Accept the Fedora Code of Conduct:
    1. Login
    2. Go to user-settings
    3. Go to tab agreements
    4. Read and accept these

3. Now you can login at weblate <https://translate.fedoraproject.org/accounts/login/>
   - Open our project overview page <https://translate.fedoraproject.org/projects/mate-desktop>, or
   - Search for the project you’d like to edit. All of our projects starting with `mate-desktop/` in their names.
